# Changelog

All notable changes to Focus Flow are documented here.

## 1.0.0 - 2026-09-14

- Added the five-screen production-ready Flutter application.
- Added English and French localization.
- Added repository-driven task completion and progress insights.
- Added unit, widget, and integration test suites.

## 0.3.0 - 2026-08-28

- Added focus timer screen and weekly progress view.
- Improved Material 3 navigation and accessibility labels.
- Added CI quality gates.

## 0.2.0 - 2026-08-12

- Added task search and completion workflow.
- Introduced immutable task models and repository abstraction.
- Added dashboard progress summary.

## 0.1.0 - 2026-07-30

- Created the initial Flutter project shell.
- Added the first dashboard prototype.
